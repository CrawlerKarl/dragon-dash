# Dragon Dash 🐉

A Dragon Ball Z–themed classic-Sonic-style adventure you can play in any browser — phone or computer.

**Play it here:** https://crawlerkarl.github.io/dragon-dash/

## The story

Frieza's forces are hunting the 7 Dragon Balls. Bulma hands Goku her Dragon Radar in West City, and the chase is on — across the rocky wasteland, through deep space, all the way to Planet Namek.

## How to play

| Action | Keyboard | Phone |
|---|---|---|
| Move | Arrow keys / WASD | drag on left side of screen |
| Jump | Z / Space | JUMP button |
| Punch / Ki Blast | X / J (tap) | KI button (tap) |
| **KAMEHAMEHA** | hold X with full Ki, release | hold KI button, release |
| Go Super Saiyan | C | SS button |
| Pause | P | ⏸ top-left |
| Mute | M | 🔇 top-right |

- **Zeni** are your health, Sonic-rings style — get hit and they scatter (grab them back!).
- Stomp enemies, punch them up close, or blast them from range.
- Follow the **Dragon Radar arrow** to find hidden Dragon Balls.
- **Go Super Saiyan** by collecting 200 zeni (30 seconds) — or find **all 7 Dragon Balls** to make it permanent.
- 4 zones, 4 bosses. Find all 7 Dragon Balls before beating Frieza for the **true ending**.

## Run locally

```
node serve.js
# open http://localhost:8423
```

No build step, no dependencies — plain HTML5 canvas + vanilla JS. All art and music are generated in code.
